# 🏛️ Bibliotheca Alexandrina Museum RAG API

This repository contains the backend and frontend for the Bibliotheca Alexandrina Antiquities Museum AI Assistant.

This Hugging Face Space hosts the FastAPI backend, which is configured via the root `Dockerfile` to run the application in the `backend/` directory on port 7860.
