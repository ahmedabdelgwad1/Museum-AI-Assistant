💡 Guide to the Metrics in the Screenshots:

  • Latency (e.g., 1.75s): It is the total time the system took to receive the question, search the database, generate the answer using the AI model, and return it.
  • Relevance Score (e.g., 0.8 or 1.0): It shows how relevant the retrieved artifact data from the Supabase Vector DB was to the user's question (1.0 means highly relevant, 0.0 means out of scope).
